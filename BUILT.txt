WHAT WAS BUILT
--------------
Stitched the existing multi-page e-commerce hub into one cohesive, working,
deployed website (storefront + admin portal):

- index.html — storefront rebuilt & polished: preloader with progress bar and
  curtain reveal, glassy sticky navbar with mobile hamburger, full-bleed photo
  hero with parallax, staggered headline reveal + gradient accent, product
  image floating animation, scrolling marquee strip with edge-fade mask,
  product grid with real photography + spec chips + hover zoom, story section
  with count-up stats, "why us" features, B2B wholesale quote form (inline
  success state), testimonials with 5-star ratings, contact/visit section with
  hours + WhatsApp CTA, and a dynamic-year footer.
- Working shopping cart (all pages): add-to-cart, live badge, slide-in drawer
  with quantity steppers + remove + INR subtotal, persisted to localStorage,
  toast confirmations.
- admin-login.html / admin-dashboard.html / admin-inventory.html /
  admin-wholesale.html — verified & favicon added; login flows to dashboard.

DESIGN DECISIONS
----------------
- Palette: near-black navy (#0e1c2f) base for dark surfaces, electric blue
  (#007aff) as the single accent, ivory paper (#f8f9ff) light sections.
- Type: Inter for everything + JetBrains Mono for mono kickers/labels; display
  headlines use tight -0.035em tracking at 800 weight, clamp() scaled
  (MotionSites-style type discipline, pulled as computed-style reference data).
- Spacing: generous py-24/32 section rhythm, 1280px content max, clamp() gutters.
- Motion: motion.dev (esm.sh CDN) — inView reveals, staggered hero load,
  scroll-linked parallax, count-up stats. All motion is progressive
  enhancement: cart + preloader run on a dependency-free script, so the site
  works even if the CDN fails; prefers-reduced-motion fully disables motion.
- Radius 12-24px, soft shadows, 1px low-opacity borders.
